# Soluciones de referencia

Las soluciones de referencia de los 60 ejercicios **viven en `../60_ejercicios.sql`**, junto a cada enunciado (es el archivo que el seed usa para calcular los hashes esperados).

En la base de datos solo se guarda el hash, nunca el texto de la solución, así que no te la encuentras por accidente al explorar `lab.ejercicio`.

Abrir `60_ejercicios.sql` y leer una solución es decisión tuya. Intenta resolver el ejercicio primero: escribe tu consulta en `respuestas/Exx.sql` y córrela con `just check Exx`.
